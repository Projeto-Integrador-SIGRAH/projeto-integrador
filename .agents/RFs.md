# Requisitos Funcionais do SIGRAH

## RF01
- O sistema deve permitir que o usuário realize login por meio de suas credenciais de acesso.

## RF02
- O sistema deve permitir o cadastro de novos usuários, mediante o preenchimento das informações necessárias.

## RF03
- O sistema deve coletar a localização atual para permitir que o usuário visualize o mapa da área.

## RF04
- O sistema deve coletar a localização atual para permitir que o usuário visualize os encanamentos representados no mapa.

## RF05
- O sistema deve permitir que o administrador desenhe, cadastre e represente um novo cano no mapa.

## RF06
- O sistema deve permitir que o usuário consulte as informações detalhadas referente a um cano selecionado.

## RF07
- O sistema deve permitir que o usuário busque e localize um cano por meio de informações de identificação ou características cadastradas.

## RF08
- O sistema deve permitir que o cidadão crie um alerta.

## RF09
- O sistema deve permitir que os alertas sejam exibidos de forma anônima no mapa para o usuário.

## RF10
- O sistema deve permitir que o administrador consiga resolver um alerta.
